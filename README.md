# Hotel-room-booking

# ✈️ Travel Booking App UI Design

## ✨ Project Overview

This is a Travel Booking App UI Design created using Figma. The application provides a simple and attractive interface for users to explore destinations, book flights, find hotels, plan trips, and manage their travel bookings.

## 🎯 Objective

The main objective of this project is to design a user-friendly travel booking application with a clean and modern interface that makes planning and booking trips easy, quick, and convenient.
